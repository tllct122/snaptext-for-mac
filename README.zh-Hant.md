# SnapText ✿

[English](README.md) | **繁體中文** | [简体中文](README.zh-Hans.md)

**從 Mac 螢幕上任何地方複製文字。**

影片裡的課堂簡報、別人傳來的截圖、不能選取文字的 PDF、圖片裡的字——按 **⇧⌘2**，框選範圍，文字就會複製到剪貼簿。使用 Mac 內置的文字辨識功能，不需要網絡，資料也不會離開你的電腦。

## 功能

- ⌨️ **一個快捷鍵**：按 ⇧⌘2、框選、完成（也可以換其他快捷鍵）
- 🈶 **中英日韓**：支援繁體和簡體中文，以及中英混合
- 📐 **保持閱讀順序**：由上到下、由左到右輸出，中文字之間不會多出空格
- ↩️ **自選換行方式**：保留螢幕上的換行，或合併成段落（適合簡報和 PDF）
- ✏️ **貼上前可修改**：彈出視窗會顯示辨識結果，改好錯字再按 Copy
- 🔳 **也能讀 QR code**：掃描螢幕上的 QR code，一鍵開啟連結
- 🕘 **最近紀錄**：選單列可以找回最近幾次的辨識結果
- 🎨 **自訂外觀**：彈出視窗風格（Glass / Light / Dark）、強調色、字型、字體大小、位置、顯示時間
- 🔒 **私隱與離線**：使用 Apple 裝置上的 Vision 框架，不需要網絡和帳號
- 🪶 **輕巧原生**：只有一個 Swift 檔案，不需要任何套件

## 安裝

需要 macOS 12 或以上。

1. 下載這個 repo（**Code → Download ZIP**），然後解壓縮
2. 打開「**終端機**」，輸入 `bash `（後面有一個空格），把 `build.sh` 拖進視窗，再按 Enter
3. 如果 macOS 要求安裝 **Command Line Tools**，安裝完成後再執行一次第 2 步
4. **允許螢幕錄製：** 系統設定 → 私隱與安全性 → **螢幕與系統錄音** → 開啟 **SnapText**。然後結束 SnapText（選單列圖示 → Quit SnapText），再從「應用程式」重新開啟

> SnapText 只會在你框選的那一刻讀取那個範圍。macOS 規定任何讀取螢幕內容的 App 都需要「螢幕錄製」權限。

## 使用方法

| 動作 | 方法 |
|---|---|
| 從螢幕複製文字 | 按 **⇧⌘2**，框選文字（按 Esc 取消） |
| 修正錯字 | 在彈出視窗中修改，然後按 **Copy** |
| 合併段落／保留換行 | 彈出視窗中的按鈕，或在 Settings 設定預設 |
| 開啟 QR code 連結 | 框選 QR code → **Open link** |
| 複製之前的結果 | 選單列圖示 → **Recent** |
| 設定 | 選單列圖示 → **Settings…**（⌘,） |
| 開機自動啟動 | 選單列圖示 → **Open at Login** |

**小貼士**
- 字太細？先放大（⌘+），字越大辨識越準。
- 中文辨識出錯？在 **Settings → Capture → Language** 選對語言，不要用 Automatic。

## 手動編譯

```bash
swiftc -O -parse-as-library SnapText.swift -o SnapText
```

建議用 `build.sh` 編譯成 App：安裝到「應用程式」後，快捷鍵和螢幕錄製權限才最穩定。
