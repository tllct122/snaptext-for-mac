# SnapText ✿

[English](README.md) | [繁體中文](README.zh-Hant.md) | **简体中文**

**从 Mac 屏幕上任何地方复制文字。**

视频里的课堂幻灯片、别人发来的截图、不能选择文字的 PDF、图片里的字——按 **⇧⌘2**，框选区域，文字就会复制到剪贴板。使用 Mac 内置的文字识别功能，不需要网络，数据也不会离开你的电脑。

## 功能

- ⌨️ **一个快捷键**：按 ⇧⌘2、框选、完成（也可以换其他快捷键）
- 🈶 **中英日韩**：支持简体和繁体中文，以及中英混合
- 📐 **保持阅读顺序**：从上到下、从左到右输出，中文字之间不会多出空格
- ↩️ **自选换行方式**：保留屏幕上的换行，或合并成段落（适合幻灯片和 PDF）
- ✏️ **粘贴前可修改**：弹出窗口会显示识别结果，改好错字再按 Copy
- 🔳 **也能读二维码**：扫描屏幕上的二维码，一键打开链接
- 🕘 **最近记录**：菜单栏可以找回最近几次的识别结果
- 🎨 **自定义外观**：弹出窗口风格（Glass / Light / Dark）、强调色、字体、字号、位置、显示时间
- 🔒 **隐私与离线**：使用 Apple 设备上的 Vision 框架，不需要网络和账号
- 🪶 **轻巧原生**：只有一个 Swift 文件，不需要任何依赖

## 安装

需要 macOS 12 或以上。

1. 下载这个仓库（**Code → Download ZIP**），然后解压
2. 打开“**终端**”，输入 `bash `（后面有一个空格），把 `build.sh` 拖进窗口，再按回车
3. 如果 macOS 提示安装 **Command Line Tools**，安装完成后再执行一次第 2 步
4. **允许屏幕录制：** 系统设置 → 隐私与安全性 → **屏幕与系统录音** → 打开 **SnapText**。然后退出 SnapText（菜单栏图标 → Quit SnapText），再从“应用程序”重新打开

> SnapText 只会在你框选的那一刻读取那个区域。macOS 规定任何读取屏幕内容的应用都需要“屏幕录制”权限。

## 使用方法

| 操作 | 方法 |
|---|---|
| 从屏幕复制文字 | 按 **⇧⌘2**，框选文字（按 Esc 取消） |
| 修正错字 | 在弹出窗口中修改，然后按 **Copy** |
| 合并段落／保留换行 | 弹出窗口中的按钮，或在 Settings 设置默认 |
| 打开二维码链接 | 框选二维码 → **Open link** |
| 复制之前的结果 | 菜单栏图标 → **Recent** |
| 设置 | 菜单栏图标 → **Settings…**（⌘,） |
| 开机自动启动 | 菜单栏图标 → **Open at Login** |

**小贴士**
- 字太小？先放大（⌘+），字越大识别越准。
- 中文识别出错？在 **Settings → Capture → Language** 选对语言，不要用 Automatic。

## 手动编译

```bash
swiftc -O -parse-as-library SnapText.swift -o SnapText
```

建议用 `build.sh` 编译成应用：安装到“应用程序”后，快捷键和屏幕录制权限才最稳定。
